> Статус: черновик v0.1 (2026-10-22). Рекомендация для ревью командой и самой Верушкой — не финальное решение.

## 1. Цветовая палитра

| Токен (Tailwind) | HEX | Роль | Доля |
|---|---|---|---|
| `obsidian` | `#080808` | Основной фон | ~70% |
| `charcoal` | `#121212` | Поверхности, карточки, расписание | ~15% |
| `chalk` | `#F5F5F7` | Заголовки, основной текст | — |
| `silver` | `#8E8E93` | Вторичный текст, мета | — |
| `fuchsia` | `#E1005A` | Единственный CTA-цвет, маркеры, hover | ≤5% |
| `gold` | `#D4AF37` | «Trophy»-акцент: подписи, eyebrow, рамки Legendary/премиум | ≤3% |
| `violet` | `#7B2CBF` | Только атмосферные свечения (градиенты), не текст | фон |

Правила:
- **Fuchsia = действие.** Ни один не-кликабельный элемент не окрашивается в фуксию целиком (кроме маркеров-точек).
- **Gold = статус.** Подпись «by Verushka Bonchinche», Legendary-бейджи, рамки индивидуальных занятий.
- Мост к старому бренду: oxblood `#990000` из Taplink можно оставить как редкий `--color-oxblood` для фото-подложек — решить после ревью.
- Контраст: `silver` на `obsidian` ≈ 6:1 (AA для body) ⓖ — проверить инструментом; золото на чёрном использовать от 14px+.

## 2. Шрифтовые пары

| Роль | Шрифт | Почему |
|---|---|---|
| Display / заголовки | **Playfair Display** (normal + italic), uppercase, tracking `0.08–0.15em` | Didone-контраст как у обложек Vogue и у текущего Taplink; **есть кириллица**. Cinzel и Syne кириллицу не поддерживают — для RU по умолчанию не подходят |
| Body / UI | **Inter** | Нейтральный, отличная кириллица, читаем в мелких размерах |
| Мета, расписание, цены | **JetBrains Mono**, uppercase, tracking `0.2–0.35em`, 11–14px | «Брутальный» runway-тег, ровные столбцы цифр |

Подключено через `next/font/google` в `src/app/layout.tsx` (`--font-display`, `--font-sans`, `--font-mono`).

Альтернатива для обсуждения: заголовки в **Bodoni Moda** (тоже Didone, кириллицы нет ⓖ — проверить) — только для EN.

Шкала: Hero `clamp(5rem, 22vw, 20rem)` · H2 `clamp(2.5rem, 7vw, 6rem)` · H3 `2rem` · body `16–18px` · mono `11–13px`.

## 3. Сетка главной страницы

12-колоночная сетка, поля `24px` (mobile) / `48px` (desktop), вертикальный ритм секций `120–160px`. Mobile-first: ~все трафик с Instagram ⓖ.

```
┌──────────────────────────────────────────────┐
│ 0. NAV  logo ✦ · Офлайн · Онлайн · Обо мне · RU/EN · [Записаться] │  sticky, blur
├──────────────────────────────────────────────┤
│ 1. HERO  мета-теги · eyebrow · VOGUE (staccato) · подпись gold    │  ✅ готово
│          CTA fuchsia + «Расписание» · marquee категорий            │
├──────────────────────────────────────────────┤
│ 2. MANIFESTO  фото в арке (main-04) + цитата                       │  parallax
│          «не только про танец, но и про комьюнити»                 │
├──────────────────────────────────────────────┤
│ 3. FORMATS  горизонтальный «подиум» из 4 карточек:                 │  runway scroll
│          Группы · Индивидуально · Runway Club · Old Way Club       │
├──────────────────────────────────────────────┤
│ 4. SCHEDULE  mono-таблица (Пн/Ср 19:20 Beginners, 20:30 Middle)    │  #schedule
│          табы Офлайн/Онлайн, цены, кнопка записи в строке          │
├──────────────────────────────────────────────┤
│ 5. ABOUT / HOUSE  био, Дом Бончинче, лого main-10                  │
├──────────────────────────────────────────────┤
│ 6. CATEGORIES  глоссарий: Catwalk, Duckwalk, Hands, Floor, Spins & Dips │ hover-видео
├──────────────────────────────────────────────┤
│ 7. COLLAB  форматы сотрудничества (шоу, судейство, бренды…) + CTA  │
├──────────────────────────────────────────────┤
```

Схема данных: расписание и цены — один источник (`src/data/classes.ts`), тексты — словари; так Hero CTA, Schedule и Formats используют одни и те же `classId` для `booking.ts`.

## 4. Интерактивные фичи

### Микро-анимации (Framer Motion)
- **Staccato reveal**: буквы/слова выезжают из-под маски с `skewY`, кривая `cubic-bezier(0.85,0,0.15,1)`, шаг 90 мс — «поза на счёт». ✅ в Hero.
- **Snap-hover** на кнопках: сдвиг `x: 4px` за 150 мс, без пружины; стрелка ↗ уезжает по диагонали.
- **Золотая подиумная линия**: `scaleX 0→1` при входе секции — разделитель вместо `<hr>`.
- **Counter-pop** для цен: цифры «щёлкают» при появлении в viewport.

### Подиумный скролл
- Секция Formats: вертикальный скролл → горизонтальное движение карточек (`useScroll` + `useTransform`, `position: sticky`). Как проход по подиуму слева направо.
- Бесконечная **marquee** категорий (✅ в Hero) + вторая, встречная, над футером.
- Лёгкий параллакс фото в арках (`y: ±8%`).

### Видео-превью
- Карточки Categories/Formats: постер-WebP → по hover (desktop) / по попаданию в центр viewport (mobile) играет беззвучный loop 3–5 с (`muted playsInline`, `preload="none"`).
- Формат: H.264 MP4 + WebM, ≤1.5 МБ на клип. **Видео-материалов на Taplink нет** — нужен запрос к владельцу (Instagram reels?).

### Доступность и производительность
- `prefers-reduced-motion` отключает marquee, параллакс и staccato (✅ в Hero).
- Декоративное движение `aria-hidden`, дубликаты marquee скрыты от screen reader.
- Изображения через `/optimize-images` → WebP + `next/image` с blur-placeholder.

## 5. Референсы ⓖ

Из общих знаний (не проверено на актуальность — открыть и сверить):
- **Vogue Runway** — mono-мета над крупной сериф-типографикой, плотные галереи look-ов.
- **Dazed / i-D** — дерзкие кропы, наложения текста на фото, uppercase-заголовки.
- **SSENSE** — минимализм, много воздуха, mono-UI.
- **Steezy / CLI Studios** — понятная структура «уровень → класс → записаться» (упомянуты в обзоре [mycodelesswebsite.com](https://mycodelesswebsite.com/dance-studio-website-design/)).
- **Steps on Broadway** — отвечает на ключевые вопросы новичка на первом экране ([zarla.com](https://www.zarla.com/inspiration/dance-studio)).
- Танцевальные номинанты [Awwwards](https://www.awwwards.com/inspiration_search/dance/) — для motion-идей.
- Контекст категорий Ballroom: [iHeartBerlin](https://www.iheartberlin.de/principles-of-voguing-a-guide-to-ballroom-categories/), [Red Bull](https://www.redbull.com/za-en/guide-to-ballroom-vogue-scene).

Подборки обзорных сайтов коммерческие и могут быть предвзяты.

3. `entry.*` ID полей Google Forms для pre-fill.
4. Тёмный фото/видео-сет под новый стиль.
5. Нужен ли польский язык.
